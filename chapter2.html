2.1 CSS是什么与三种引入方式

让网页从朴素变好看

2.1 CSS是什么与三种引入方式

CSS 的全称是「层叠样式表」（Cascading Style Sheets）。HTML 负责页面里有什么，CSS 负责这些内容长什么样——颜色、大小、位置、间距、边框、背景，全都归 CSS 管。

用装修打个比方：HTML 是一套「毛坯房」，有墙、有门、有窗户，但光秃秃的；CSS 就是「装修」——刷成什么颜色的墙、铺什么地板、家具怎么摆，房子立刻就好看了。

把 CSS 写进网页有三种方式：

① 内联样式：直接写在某个标签的 style 属性里，只对这一个标签生效。改起来最麻烦，不推荐大量使用。

② 内部样式表：把所有样式集中写在 <head> 里的 <style> 标签中，作用范围是当前这一个页面。适合做单个小页面、练习时用。

③ 外部样式表：把样式单独写在一个 .css 文件里，再用 <link> 标签引入到 HTML 中。一个 CSS 文件可以被很多页面同时引用。

做网站推荐使用「外部样式表」：全站样式集中在一个文件里，改一处，所有页面同时生效，维护起来最省事。

2.2 选择器

CSS 的每条规则都长这样：选择器 { 属性: 值; }。选择器的作用，就是「告诉浏览器：我要美化谁」。它负责从一大堆标签里，精准找到你想改样式的那一个或那一类标签。

最常用的三种选择器：

标签选择器：直接写标签名，例如 p { }，会选中页面上所有的 <p> 段落，统一样式。

类选择器：在类名前加一个点，例如 .box { }，HTML 里用 class="box" 来标记。一个类可以给很多标签用，一个标签也能同时用好几个类。

id 选择器：在 id 名前加井号，例如 #title { }。id 在一个页面里必须唯一，只能给一个标签用。

类选择器最灵活、用得最多。想让全站按钮、卡片长得一模一样，就是靠统一的 class 来实现的。

2.3 颜色与字体

颜色有三种常见写法：

命名色：直接写颜色英文，如 red、blue、green，简单但可选颜色少。

十六进制：以 # 开头加六位，如 #2563eb（本教程的主蓝色）。这是网页里最常用的写法。

RGB：rgb(红, 绿, 蓝)，如 rgb(37, 99, 235)，和上面的十六进制是同一个蓝色。

控制文字外观的几个常用属性：

color 文字颜色；font-family 字体族；font-size 字号（单位 px）；font-weight 粗细（normal 正常 / bold 加粗）；text-align 对齐方式（left / center / right）。

把它们组合起来，就能轻松地做出一行颜色漂亮、大小合适、居中对齐的文字。

2.4 盒子模型

这是 CSS 里最重要的概念之一：浏览器会把每一个 HTML 元素，都看成一个「盒子」。这个盒子从内到外一共四层：

content 内容：盒子最中间，真正放文字、图片的地方。

padding 内边距：内容与边框之间的空白，把内容「往里推」。

border 边框：围着内容那一圈的线，可以设置粗细、颜色、圆角。

margin 外边距：盒子与盒子之间的距离，把这个盒子「往外推」。

一句话记住：padding 是在盒子内部撑出空白，margin 是把盒子和旁边元素推开。卡片之间留出的呼吸感，主要靠它们。

2.5 Flex布局与卡片样式

以前要把一排元素整齐地横着排，写法很麻烦。现在只要给容器加上 display: flex，它里面的子元素就会自动横向排成一行，非常省事。

Flex 里两个最常用的对齐属性：

justify-content：控制子元素在「主轴」（默认横向）上的对齐，常用值有 center 居中、space-between 两端对齐。

align-items：控制子元素在「交叉轴」（默认纵向）上的对齐，常用值 center 垂直居中。

配合前面学的 padding、border、border-radius，就能把一个个内容块做成漂漂亮亮的卡片，再用 Flex 让它们并排整齐排列。

学会 Flex，你就能做出本教程首页那种「一排卡片整齐排列」的效果——这也是现代网页最常见的布局方式。

关键代码 ① CSS 的三种引入方式

同一段样式，可以用三种不同的方式写进页面，适用场景各不相同。

/* ① 内联样式：写在标签的 style 里，只作用于这一个标签 */ <p style="color: red; font-size: 20px;">我是红色大字</p> /* 适用：临时改一个标签，不推荐大量使用 */ /* ② 内部样式表：写在 <head> 的 <style> 里，作用本页 */ <style> p { color: blue; } /* 本页所有段落变蓝 */ </style> /* 适用：单个小页面、做练习时 */ /* ③ 外部样式表：单独的 style.css 文件，用 link 引入 */ <link rel="stylesheet" href="style.css"> /* 适用：正式网站，多个页面共用一份样式，推荐 */

关键代码 ② 三种选择器

标签、类、id 三种选择器，优先级依次升高。

/* 标签选择器：选中所有 <p> 标签，全站段落统一 */ p { color: #334155; line-height: 1.8; } /* 类选择器：用 class="card" 标记的元素，最灵活最常用 */ .card { background: white; padding: 16px; } /* id 选择器：用 id="title" 的元素，一个页面只能用一次 */ #title { font-size: 26px; color: #0f172a; } /* 优先级：id 选择器 # > 类选择器 . > 标签选择器 */
记忆要点：
1. 标签选择器写标签名，类选择器前面加点 .，id 选择器前面加井号 #
2. 一个类可以反复用在很多元素上，id 在页面里必须唯一
3. 优先级：id > class > 标签，想让样式生效就用更具体的选择器

关键代码 ③ 一个完整的卡片样式

把前面学过的属性组合起来，做出一张好看的卡片。

<!-- 这是对应的 HTML 结构 --> <div class="card"> <h3>卡片标题</h3> <p>这是卡片里的一段说明文字。</p> </div> /* 这是对应的 CSS 样式 */ .card { background: #ffffff; /* 卡片背景白色 */ border: 1px solid #e2e8f0; /* 一圈浅灰边框 */ border-radius: 10px; /* 四角圆润 */ padding: 20px; /* 内容与边框的内边距 */ box-shadow: 0 2px 8px rgba(0,0,0,0.08); /* 淡淡的阴影 */ } .card:hover { box-shadow: 0 4px 16px rgba(0,0,0,0.15); /* 鼠标移上去阴影变深 */ } .card h3 { color: #2563eb; /* 标题用主题蓝 */ margin-bottom: 8px; }
记忆要点：
1. 一张好看的卡片 = 白底 + 边框 + 圆角 + 内边距 + 阴影
2. hover 是鼠标悬停时的效果，能让卡片「活」起来
3. CSS 属性一句一个分号，最后一句可省略
