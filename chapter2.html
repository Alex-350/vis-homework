第2章 Flex弹性布局

现代一维布局首选方案，掌握弹性排列与对齐

2.1 Flex基本概念

Flexbox（弹性盒子）是2009年提出、2017年正式标准化的一维布局模型，专门为解决「单行/单列内元素的排列、对齐、空间分配」问题而设计。

Flex解决了什么痛点

  • 垂直居中：之前需要用各种hack技巧，现在一行代码搞定
  • 等分空间：多个元素自动平分宽度，无需计算百分比
  • 弹性伸缩：空间多就撑满，空间少就压缩，自适应容器
  • 顺序调整：不用改HTML，只用CSS就能调换元素顺序

核心术语体系

核心优势：维度分离。主轴管排列和分配，交叉轴管对齐。两套系统独立工作，互不干扰。

2.2 主轴方向与对齐

主轴方向 flex-direction

定义主轴的方向，也就是弹性项排列的方向。

  • row
  • row-reverse
  • column
  • column-reverse

主轴对齐 justify-content

控制弹性项在主轴上的分布方式，是最常用的Flex属性之一。

属性值 效果 典型应用
flex-start 靠起始线对齐 默认状态、左对齐菜单
center 居中对齐 按钮组、分页、居中标题
flex-end 靠终止线对齐 右对齐按钮、底部操作栏
space-between 两端对齐，中间平分空间 导航栏、两端分布布局
space-around 每个元素两侧空间相等 卡片组、均匀分布图标
space-evenly 所有间距完全相等 精确均匀分布

2.3 交叉轴与换行

交叉轴对齐 align-items

控制弹性项在交叉轴上的对齐方式，单行时生效。

  • stretch
  • flex-start
  • center
  • flex-end
  • baseline

换行模式 flex-wrap

默认情况下，所有弹性项挤在一行，空间不足时自动压缩。设置换行后，空间不足会自动换到下一行。

  • nowrap
  • wrap
  • wrap-reverse

多行对齐 align-content

只有在换行模式下，有多行弹性项时才生效。控制行与行之间在交叉轴的分布方式。

常见混淆：align-items管单行对齐，align-content管多行分布。只有一行时align-content无效。

2.4 弹性比例与排序

放大比例 flex-grow

当主轴有剩余空间时，弹性项按比例瓜分剩余空间。默认值0，不放大。

  • 所有项flex-grow都为1：平分剩余空间
  • A为2，B为1：剩余空间分3份，A拿2份，B拿1份
  • 注意：分配的是「剩余空间」，不是总宽度

缩小比例 flex-shrink

当主轴空间不足时，弹性项按比例压缩。默认值1，自动压缩。

  • 设为0：禁止压缩，元素保持原始宽度
  • 数值越大，压缩得越多

基准尺寸 flex-basis

在分配空间之前，弹性项的初始尺寸。可以是像素、百分比，默认auto（由内容决定）。

排序 order

控制弹性项的排列顺序，数值越小越靠前。默认值0。可以是负数。

注意：order只改变视觉顺序，不改变DOM顺序。屏幕阅读器和Tab键仍然按HTML顺序访问。

2.5 经典Flex布局场景

场景1：完美居中

父元素设置三行代码，实现子元素水平垂直同时居中。这是Flex最广为人知的用法。

场景2：两端对齐导航栏

左侧品牌，右侧菜单，自动贴靠两端。用space-between实现，无需浮动，无需margin。

场景3：自适应卡片流

flex-wrap: wrap + gap，卡片自动换行，容器宽就多排几列，容器窄就少排几列。

场景4：底栏固定按钮

一个按钮固定宽度，另一个按钮撑满剩余空间。用flex: 0 0 100px和flex: 1配合实现。

场景5：等高列

同一行的列自动保持等高，无需设置固定高度。内容多的列有多高，其他列就跟着多高。

2.1 启用Flex布局

/* 父容器：弹性容器 */ .flex-container { display: flex; flex-direction: row; flex-wrap: nowrap; gap: 16px; } /* 子元素：弹性项 */ .flex-item { flex: 1 1 auto; }
gap属性是现代写法，直接设置元素间距，比margin更干净，不会出现边缘边距折叠问题。

2.2 主轴对齐完整写法

.container { display: flex; /* 主轴方向 */ flex-direction: row; /* 主轴对齐 */ justify-content: flex-start; /* 交叉轴对齐 */ align-items: stretch; /* 换行方式 */ flex-wrap: wrap; }

2.3 完美居中代码

/* 三行代码实现完美居中 */ .center-box { display: flex; justify-content: center; align-items: center; height: 300px; }

2.4 弹性比例控制

.item-fixed { flex: 0 0 200px; /* 不放大不缩小，固定200px */ } .item-fill { flex: 1 1 auto; /* 撑满剩余空间 */ } .item-double { flex-grow: 2; /* 占2份剩余空间 */ } .item-no-shrink { flex-shrink: 0; /* 禁止压缩 */ }

2.5 导航栏布局模板

.navbar { display: flex; align-items: center; justify-content: space-between; padding: 0 24px; height: 64px; } .navbar__brand { font-weight: 600; } .navbar__menu { display: flex; gap: 24px; list-style: none; }
