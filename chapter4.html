4.1 多页面网站是什么

把多个页面拼成一个完整网站

4.1 多页面网站是什么

一个网站通常不是一个单独的 HTML 文件，而是多个 HTML 页面用超链接串起来形成的整体。每个页面负责一块内容，点一下链接就能跳到另一个页面。

本教程本身就是一个多页面网站：index.html 是首页，chapter1.html 到 chapter5.html 是五个章节页，它们之间互相跳转，组成一整套教程。

单页网站 = 一篇文章；多页面网站 = 一整本书。<a> 标签就相当于书目录里的页码，点一下就能跳到对应章节。

4.2 文件目录结构

做网站时，所有 HTML 文件最好放在同一个文件夹里。文件多了以后，可以按类型建立子文件夹来分类管理：

css/ 放样式文件、js/ 放脚本文件、images/ 放图片资源。这样网站再大也不会乱。

本教程采用最简单的扁平结构：index.html 和 chapter1.html ~ chapter5.html 全部放在同一个文件夹里，彼此平级，谁也不嵌套谁。

4.3 超链接与 a 标签

把页面连起来靠的是 <a> 标签，基本写法是：<a href="目标">显示文字</a>。

href 属性里写要跳转的地址，用户点击后浏览器就会打开这个新地址。例如 <a href="chapter2.html">第2章</a>，点「第2章」就跳到 chapter2.html。

如果加上 target="_blank"，链接会在新标签页里打开，而不是覆盖当前页面。这个用法主要用在跳转到本站以外的外部网址时。

4.4 相对路径规则

这是本章最关键的知识点。href 里写的地址叫「路径」，最常用的是相对路径——相对于当前这个文件去描述目标文件在哪。三种情况：

① 同目录文件：直接写文件名即可，如 href="chapter2.html"。

② 当前目录下的子文件夹：文件夹名/文件名，如 href="css/style.css"，也可以写成 href="./css/style.css"。

③ 上一级目录：用 ../ 表示「退回上一层」，如 href="../index.html" 表示回到上一级文件夹里的首页。

写路径前先问自己两个问题：我「当前在哪个文件」？目标文件「相对我现在在哪」？想清楚这两点，路径就不会写错。

4.5 导航栏与返回

把多个页面串起来后，还需要让用户能方便地在页面之间来回跳。顶部导航栏就是一组固定的链接，放在每个页面顶部，让用户随时切换章节。

同时，每个子页面都应该放一个「← 返回首页」链接回到 index.html，这样用户从首页进得来、也回得去，形成一个完整的闭环。本教程每个章节页顶部就有这个返回链接。

关键代码 ① 顶部导航栏

一段 <nav> 里放多个 <a>，分别链接到首页和各个章节页，粘贴到每个页面顶部即可复用。

<!-- nav 表示这是页面导航区域 --> <nav> <!-- 链接到首页，href 写相对路径 --> <a href="index.html">首页</a> <!-- 链接到第1章页面 --> <a href="chapter1.html">第1章</a> <!-- 链接到第2章页面 --> <a href="chapter2.html">第2章</a> <!-- 链接到第3章页面 --> <a href="chapter3.html">第3章</a> <!-- 链接到第4章页面 --> <a href="chapter4.html">第4章</a> </nav>

关键代码 ② 首页与章节页互跳

首页卡片上放「进入章节」链接；章节页顶部放「返回首页」链接，形成双向跳转。

<!-- 这是写在首页 index.html 里的卡片链接 --> <!-- href 指向同目录下的章节页，相对路径直接写文件名 --> <a href="chapter1.html">进入章节 →</a> <--------------------------------------------------> <!-- 这是写在章节页（如 chapter4.html）顶部的返回链接 --> <!-- 两个文件在同一目录，直接写 index.html 即可回到首页 --> <a href="index.html">← 返回首页</a>

关键代码 ③ 新标签页打开外部链接

跳到本站以外的网址时，加上 target="_blank" 在新标签页打开。

<!-- href 写完整网址（绝对路径），跳转到外部网站 --> <!-- target="_blank" 的作用：在新标签页打开，不离开本站 --> <a href="https://www.example.com" target="_blank">点这里新标签打开</a> <!-- 注意：本站内部页面之间互跳，不要加 target="_blank"， --> <!-- 否则每点一次都新开一个标签，用户体验很差 -->
记忆要点：
1. 导航栏用 <nav> 包裹一组 <a>，每个页面复用同一份
2. 首页 → 章节、章节 → 首页，靠相对路径互跳，形成闭环
3. 只有跳外部网址才加 target="_blank"，站内互跳不加
