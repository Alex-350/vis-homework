第1章 网页基础与HTML结构

从零认识网页本质，掌握HTML核心语法与常用标签

1.1 认识网页

我们平时在浏览器中看到的网页，本质上就是一个后缀为 .html 的纯文本文件。浏览器读取文件中的标签代码，将其渲染成图文并茂的可视化页面。

网页开发的三大核心技术各司其职：

  • HTML —— 网页的骨架，定义页面包含哪些内容（标题、段落、图片、按钮等）
  • CSS —— 网页的外观，定义内容的样式（颜色、大小、位置、排版）
  • JavaScript —— 网页的行为，定义页面的交互逻辑（点击、动画、数据处理）
入门类比：HTML 是毛坯房的墙体结构，CSS 是装修和家具，JavaScript 是家电和智能控制系统。

1.2 HTML基本结构

HTML 使用「标签」来标记内容，绝大多数标签成对出现，分为开始标签和结束标签，标签之间可以嵌套形成层级结构。

一个标准的 HTML 文档必须包含三大部分：

  • <!DOCTYPE html>：文档类型声明，告诉浏览器使用 HTML5 标准解析
  • <head>：头部区域，存放页面配置信息（编码、标题、样式引用），用户不可见
  • <body>：主体区域，存放所有用户可见的页面内容

标签的核心语法规则：标签名用尖括号包裹，结束标签带斜杠；标签可以添加属性来扩展功能。

1.3 常用文本标签

文本是网页最基础的内容形式，HTML 提供了一套完整的标签来定义文本的语义和层级。

标题标签 h1~h6 共六级，h1 权重最高，一个页面建议只出现一次，用于页面主标题。

段落标签 p 用于包裹普通文本，浏览器会自动在段落前后添加间距。

常用文本格式化标签： strong 表示重要强调（加粗）， em 表示语气强调（倾斜）， br 表示强制换行， hr 表示水平分割线。

编写原则：优先使用语义化标签，而不是单纯用样式标签。用 strong 而不是 b，用 em 而不是 i。

1.4 图片与链接

图片标签 img 是典型的单标签，通过 src 属性指定图片地址，alt 属性指定图片加载失败时的替代文字。

超链接标签 a 是网页的核心特性，通过 href 属性指定跳转目标地址。

路径分为两种： 相对路径：相对于当前文件的位置，适合站内跳转； 绝对路径：完整的网址，适合跳转到外部网站。

target="_blank" 属性可以让链接在新标签页中打开，避免离开当前页面。

1.5 列表与表格

列表分为无序列表 ul 和有序列表 ol，列表项都用 li 标签包裹。无序列表用于展示并列内容，有序列表用于有先后顺序的内容。

表格由 table 标签定义，内部结构包括： thead 表头、 tbody 表体、 tr 行、 th 表头单元格、 td 普通单元格。

表格适合展示二维结构化数据，不建议用来做页面布局。

1.1 网页三大技术角色示意

通过注释可以清晰看到 HTML、CSS、JavaScript 在文件中的位置和分工。

<!-- HTML：负责结构和内容 --> <!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <title>网页示例</title> /* CSS：负责样式和外观 */ <style> h1 { color: blue; } </style> </head> <body> <h1>你好，网页</h1> <button id="btn">点击我</button> <!-- JavaScript：负责交互和行为 --> <script> btn.onclick = function() { alert('点击了按钮') } </script> </body> </html>
分工原则：结构、样式、行为三者分离。不要在 HTML 标签里写大量样式，不要在 CSS 里写逻辑。

1.2 标准HTML完整骨架

这是每个网页都必须具备的最小完整结构。

<!-- 文档类型声明：必须放在第一行 --> <!DOCTYPE html> <!-- 根标签：整个网页的容器 --> <html lang="zh-CN"> <!-- 头部：页面元信息 --> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>页面标题</title> </head> <!-- 主体：可见内容区域 --> <body> 页面内容写在这里 </body> </html>

1.3 文本标签完整示例

<!-- 六级标题 --> <h1>一级标题</h1> <h2>二级标题</h2> <h3>三级标题</h3> <!-- 段落与文本格式化 --> <p>这是一个普通段落，包含<strong>加粗文字</strong>和<em>倾斜文字</em>。</p> <p>第一行文字<br> 第二行文字（强制换行）</p> <hr> <p>分割线下方的内容</p>

1.4 图片与链接代码

<!-- 图片标签 --> <img src="images/photo.jpg" alt="风景照片" width="400"> <!-- 站内链接（相对路径） --> <a href="chapter2.html">跳转到第2章</a> <!-- 站外链接（绝对路径） --> <a href="https://www.baidu.com" target="_blank">打开百度</a> <!-- 锚点链接：跳转到当前页面指定位置 --> <a href="#sec1">回到顶部</a>
路径注意事项：相对路径中，../ 表示上一级文件夹，./ 表示当前文件夹。路径错误会导致图片不显示、链接404。

1.5 列表与表格代码

<!-- 无序列表 --> <ul> <li>苹果</li> <li>香蕉</li> <li>橙子</li> </ul> <!-- 有序列表 --> <ol> <li>第一步：新建文件</li> <li>第二步：编写代码</li> <li>第三步：保存预览</li> </ol> <!-- 表格 --> <table> <thead> <tr> <th>姓名</th> <th>年龄</th> </tr> </thead> <tbody> <tr> <td>张三</td> <td>20</td> </tr> </tbody> </table>
浏览器实际渲染效果：HTML 定义内容，CSS 控制外观，JS 响应用户操作。
