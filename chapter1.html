第1章 布局基础理论

理解底层原理，掌握布局的核心思维

1.1 布局的本质

页面布局，本质上是在二维平面内解决两个核心问题：元素放在什么位置、元素占据多大空间。所有CSS布局技术，无论语法如何变化，最终都是在控制元素的尺寸和坐标。

布局技术的演进历史

  • 表格布局时代：利用table标签的行列特性做布局，优点是简单兼容，缺点是语义混乱、渲染慢、难以维护
  • 浮动布局时代：利用float属性实现多列布局，是Web2.0时期的主流方案，缺点是会脱离文档流，需要清除浮动
  • 定位布局时代：利用position属性精确控制位置，适合弹窗、悬浮层，不适合整体页面骨架
  • 现代布局时代：Flexbox + Grid，专门为布局设计的语法体系，语义清晰、功能强大、可维护性强
核心思想：先理解规则，再写代码。好的布局不是靠试错调出来的，而是知道每一行代码为什么生效、会产生什么影响。

1.2 盒子模型深度解析

页面中所有元素本质都是一个矩形盒子，由内到外分为四层：内容区content、内边距padding、边框border、外边距margin。这是所有布局的基础单元。

两种盒子模型对比

特性 content-box（标准） border-box（IE）
width定义 仅内容区宽度 内容+内边距+边框
加padding后 盒子整体变宽 内容区挤压，总宽不变
直观性 符合物理直觉 符合设计直觉
布局可控性 差，尺寸容易超出预期 好，设置多少就是多少

外边距折叠问题

正常文档流中，两个垂直方向的外边距相遇时，不会相加，而是取较大值，这就是外边距折叠。这是新手最容易踩坑的布局问题之一。

  • 发生条件：同属正常文档流、块级元素、垂直方向、没有边框或内边距隔开
  • 解决方法：加border/padding隔开、触发BFC、使用flex/grid布局

1.3 正常文档流与BFC

不加任何布局属性时，浏览器默认的元素排列规则就是正常文档流。这是所有布局的基准状态，所有布局技术本质上都是在打破或修改正常流。

元素的三种流动类型

  • ：独占一行，可设宽高，上下margin有效。代表：div、p、h1-h6、section
  • ：并排排列，宽高无效，上下margin无效。代表：span、a、strong、em
  • ：并排排列，可设宽高，兼具两者特性。代表：img、button、input

BFC（块级格式化上下文）

BFC是一个独立的渲染区域，内部元素的布局不会影响到外部。可以理解为页面中的一个「隔离容器」。

  • 触发方式：overflow:hidden、float不为none、position:absolute/fixed、display:flex/grid
  • 典型用途：清除浮动、解决外边距折叠、两栏自适应布局

1.4 现代布局方案对比

现代CSS有三套核心布局系统，各有分工，没有谁替代谁，选择正确的工具做正确的事。

布局方案 维度 核心优势 最佳场景
Flexbox 一维 对齐、分配空间、弹性伸缩 导航栏、按钮组、单行卡片
Grid 二维 行列同时控制、区域命名、精确划分 页面骨架、仪表盘、图片网格
Positioning 坐标定位 精确位置、层叠、脱离文档流 弹窗、悬浮按钮、角标、遮罩
选型口诀：一维用Flex，二维用Grid，固定位置用Position。大多数页面是三者组合使用。

1.5 优秀布局的设计原则

1. 最小惊讶原则

元素的行为应该符合用户的预期。按钮看起来像按钮，链接看起来像链接，可点击区域足够大。布局变化时，用户能猜到哪里变了、为什么变。

2. 流动优先原则

默认让内容决定尺寸，而不是写死固定值。布局应该像水一样适应容器，而不是反过来。多使用相对单位，少用绝对像素。

3. 关注点分离原则

结构（HTML）、样式（CSS）、行为（JavaScript）三者分离。不要在HTML里写样式，不要在CSS里写逻辑，不要用JS做纯布局的事。

4. 渐进增强原则

基础功能在所有设备都能用，高级特性在支持的设备上锦上添花。布局不应该因为某个特性不支持就彻底崩溃。

1.1 全局重置：现代布局标配

所有布局项目的第一行CSS，统一盒子模型，清除默认边距，避免浏览器差异。

/* 全局使用 border-box 盒子模型 */ *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } body { line-height: 1.6; font-family: system-ui, sans-serif; }
为什么这是标配：border-box模式下，设置width: 300px后，最终盒子就是300px宽，padding和border向内挤压，不撑大盒子，布局尺寸完全可控。

1.2 盒子模型完整属性

.box { /* 内容区尺寸 */ width: 200px; height: 100px; min-width: 100px; max-width: 400px; /* 内边距：上 右 下 左（顺时针） */ padding: 20px 16px 20px 16px; /* 简写：上下 左右 */ padding: 20px 16px; /* 边框：粗细 样式 颜色 */ border: 2px solid #2563eb; border-radius: 8px; /* 外边距 */ margin: 24px auto; /* 上下24px，左右居中 */ }

1.3 display属性大全

/* 块级：独占一行 */ display: block; /* 行内：并排流动 */ display: inline; /* 行内块：并排+可设尺寸 */ display: inline-block; /* 弹性布局 */ display: flex; /* 网格布局 */ display: grid; /* 隐藏元素，不占空间 */ display: none;

1.4 BFC触发代码

/* 最常用触发方式 */ .bfc { overflow: hidden; } /* 现代布局自动触发BFC */ .flex-container { display: flex; /* flex容器天然是BFC */ } .grid-container { display: grid; /* grid容器天然是BFC */ }

1.5 居中布局方案汇总

/* 方案1：Flex 完美居中（推荐） */ .center-flex { display: flex; justify-content: center; align-items: center; } /* 方案2：Grid 一行居中 */ .center-grid { display: grid; place-items: center; } /* 方案3：绝对定位+位移 */ .center-absolute { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
