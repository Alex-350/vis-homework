3.1 认识JavaScript

让网页动起来、能交互

3.1 认识JavaScript

如果说 HTML 搭起了网页的骨架、CSS 做好了装修，那么 JavaScript（简称 JS） 就是网页的「灵魂」，相当于家电里的智能设备。有了它，网页才会动、才能响应你的操作——比如点击按钮弹出提示、输入内容实时校验、图片轮播切换。

JS 代码写在 <script> 标签里，为了保证页面元素加载完再执行，通常把它放在 </body> 结束标签之前。

HTML 搭骨架、CSS 做装修、JavaScript 装智能，三者配合起来，才是一个完整、能用、能动的网页。

3.2 变量与数据类型

变量就像一个贴了标签的盒子，用来存放数据。用 let 声明的变量以后可以改值，用 const 声明的是常量，一旦赋值就不能再改。例如 let count = 0; 表示新建一个叫 count 的变量，初始值是 0。

常用的数据类型有：数字 number（如 0、3.14）、字符串 string（要用引号包起来，如 "你好"）、布尔 boolean（只有 true 真 / false 假两种）、数组 array（用方括号存放一串数据，如 [1, 2, 3]）。

注意：单个等号 = 在 JS 里不是「等于」，而是「赋值」——把右边的值放进左边的变量里。判断是否相等要用两个等号 == 或三个等号 ===。

3.3 函数

函数就是把一段可以重复使用的代码「打包」起来，取个名字。用 function 关键字定义，写完后用「函数名()」的形式就能调用执行。例如：

// 定义一个加法函数，接收两个参数 a 和 b function add(a, b) { return a + b; // 把结果返回出去 } // 调用函数，得到 5 let result = add(2, 3);
函数就是「做好的工具」：先把工具造好（定义），以后想用的时候按一下（调用）它就执行一次。

3.4 事件监听

网页平时在「等」用户操作，这叫事件监听。用 element.addEventListener('click', 函数) 给某个元素绑定一个事件：一旦发生对应操作，就自动执行指定的函数。

常用事件有：click（鼠标点击）、mouseover（鼠标移上去）、input（输入框内容变化）。整个过程就是：用户点按钮 → 触发事件 → 自动执行对应的函数。

3.5 DOM操作与Tab切换

DOM 就是浏览器把网页里的所有标签，变成一棵可以用 JS 操作的「对象树」。我们可以用 document.querySelector('选择器') 选中页面上的元素，然后对它进行操作：

用 classList.add / remove / toggle 来增删切换 class，用 textContent 来修改元素里的文字。

本教程每章的「讲解 / 关键代码 / 演示」Tab 切换，用的正是这套原理：给按钮绑定 click 监听 → 点击时切换 active 类 → 有 active 的内容显示、没有的隐藏。

关键代码 ① 点击计数按钮

一个完整可运行的例子：点一次按钮，数字就加 1。先写好 HTML 元素，再用 JS 给按钮加上点击逻辑。

<!-- 第一步：在页面上放一个按钮和一个显示数字的段落 --> <button id="countBtn">点我</button> <p id="show">0</p> // 第二步：编写 JS，放在 </body> 之前 // 新建一个变量，用来记录点击次数，初始为 0 let count = 0; // 用 id 选中页面上的按钮和显示用的段落 const btn = document.getElementById('countBtn'); const show = document.getElementById('show'); // 给按钮绑定点击事件，每次点击都执行后面的函数 btn.addEventListener('click', function () { count = count + 1; // 次数加 1 show.textContent = count; // 把最新的数字写回段落里显示 });
记忆要点：
1. HTML 负责「摆好元素」，JS 负责「给元素加行为」，两者通过 id 联系起来
2. addEventListener('click', 函数) 就是「监听点击，然后执行」
3. textContent 用来修改元素里显示的文字

关键代码 ② 本教程的 Tab 切换

下面这段就是本章 3.5 讲的 DOM 实操，也是本页底部真正运行的代码，逐行看一遍就懂了。

// 选中页面上所有 Tab 按钮和所有 Tab 内容区 const tabBtns = document.querySelectorAll('.tab-btn'); const tabContents = document.querySelectorAll('.tab-content'); // 逐个给每个按钮绑定点击事件 tabBtns.forEach(btn => { btn.addEventListener('click', () => { // 读取按钮身上 data-tab 的值，如 lecture / code / demo const tabName = btn.getAttribute('data-tab'); // 先移除所有按钮的 active，再给当前按钮加上 active tabBtns.forEach(b => b.classList.remove('active')); btn.classList.add('active'); // 先隐藏所有内容区，再显示 id 为 tab-xxx 的那一个 tabContents.forEach(content => content.classList.remove('active')); document.getElementById('tab-' + tabName).classList.add('active'); }); });
记忆要点：
1. querySelectorAll 选中「一批」元素，forEach 遍历它们
2. classList.remove / add 就是增删 class，从而控制样式和显示
3. 切换 Tab 的本质：同一时间只有一个元素带 active

常用事件 vs 触发时机

事件名 什么时候触发
click鼠标点击（按下并松开）某个元素时
mouseover鼠标指针移动到某个元素上方时
input输入框里的内容发生变化时（边打字边触发）
keydown在键盘上按下任意一个按键时
