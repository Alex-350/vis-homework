第3章 Grid网格布局

二维布局终极方案，行列同时精准控制

3.1 Grid基础概念

CSS Grid 是2017年正式标准化的二维布局系统，可以同时控制行和列两个方向的排列、尺寸和对齐，是复杂页面布局的首选方案。Flex擅长一维排列，Grid擅长二维规划。

Grid vs Flex：怎么选

维度 Flexbox Grid
布局维度 一维（行或列二选一） 二维（行和列同时）
内容优先 ✅ 内容决定布局，弹性适应 ❌ 先定义轨道，内容填充
布局优先 ❌ 难以精确控制行列 ✅ 精确规划结构
适用场景 导航栏、按钮组、单行卡片 页面骨架、仪表盘、图片网格

核心术语

核心优势：结构与内容分离。先在父容器定义好布局骨架，子元素只需要指定放在哪里，不需要管尺寸和位置。

3.2 轨道定义与尺寸单位

轨道定义语法

grid-template-columns 定义列轨道，grid-template-rows 定义行轨道。多个尺寸用空格分隔，有几个值就有几条轨道。

尺寸单位详解

  • px
  • %
  • auto
  • fr
  • minmax(min, max)

repeat() 函数

快速创建重复轨道，避免重复书写。repeat(3, 1fr) 等价于 1fr 1fr 1fr。

fr单位是Grid的灵魂：它分配的是「剩余空间」，不是总空间。先扣除固定尺寸轨道，剩下的空间按fr比例瓜分。

3.3 区域命名与元素放置

grid-template-areas 可以给网格中的矩形区域命名，用字符串画出布局结构图，是Grid最具可读性的特性。

命名规则

  • 每一行用一个字符串表示，字符串内的单词代表一列
  • 相同的单词连在一起形成一个矩形区域
  • 用 . 表示空单元格，不放置任何内容
  • 区域必须是矩形，不能有L形等不规则形状

元素放置方式

为什么推荐命名区域：修改布局只需要改父容器的areas定义，子元素位置自动变化。响应式布局断点里改一行代码就能换整个布局。

3.4 对齐与间距

三级对齐体系

对齐级别 水平方向 垂直方向 作用对象
整个网格 justify-content align-content 所有轨道整体
单元格内 justify-items align-items 单元格内的元素
单个元素 justify-self align-self 单独某个子元素

间距控制

  • gap
  • row-gap
  • column-gap

gap是现代布局标准属性，比margin干净，不会出现边缘折叠问题，也不会让首末元素偏离对齐。

3.5 Grid典型应用场景

场景1：整体页面骨架

页眉、左侧导航、主内容、右侧栏、页脚的经典布局。用Grid命名区域实现，结构清晰，响应式调整方便。

场景2：图片画廊

等宽等高的整齐图片网格，或者瀑布流效果。配合object-fit控制图片裁剪。

场景3：数据仪表盘

多个数据卡片、图表、指标模块的复杂排列。不同尺寸的卡片占据不同的行列跨度。

场景4：表单布局

标签与输入框的对齐排列，多列表单。Grid可以轻松实现标签右对齐、输入框左对齐的专业表单。

场景5：自动响应式卡片

auto-fill + minmax() 组合，无需媒体查询，自动根据容器宽度调整列数。

3.1 基础网格定义

.grid-container { display: grid; /* 3列等宽 */ grid-template-columns: repeat(3, 1fr); /* 行高自动适应内容 */ grid-template-rows: auto; /* 单元格间距 */ gap: 16px; }

3.2 混合尺寸轨道

/* 固定侧边栏 + 弹性主内容 */ .page-layout { display: grid; grid-template-columns: 240px 1fr; grid-template-rows: 64px 1fr 48px; gap: 0; min-height: 100vh; }
1fr 会自动占满剩余空间，是最常用的Grid尺寸单位。

3.3 命名区域布局

.container { display: grid; grid-template-columns: 200px 1fr 200px; grid-template-rows: 60px 1fr 40px; grid-template-areas: "header header header" "sidebar main rightbar" "footer footer footer"; } .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .rightbar { grid-area: rightbar; } .footer { grid-area: footer; }

3.4 跨单元格放置

/* 从第1列线到第3列线 */ .item-wide { grid-column: 1 / 3; } /* 跨2行 */ .item-tall { grid-row: span 2; } /* 从第2列开始，跨3列 */ .item-mid { grid-column: 2 / span 3; }

3.5 自动响应式网格

/* 自动填充，最小280px，自动适应列数 */ .responsive-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 20px; }
拖动滑块调整列数、间距和元素数量，实时观察网格布局的变化。
