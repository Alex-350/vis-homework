第5章 经典布局案例实战

即学即用的五大常用布局模板

5.1 顶部导航栏

网页最常见的布局模式，左侧品牌标识，右侧菜单列表，整体垂直居中。是几乎所有网站的标配组件。

设计要点

  • 两端对齐：用 justify-content: space-between 实现，无需浮动和margin
  • 垂直居中：align-items: center，一行代码解决历史难题
  • 菜单本身也是Flex容器，控制菜单项间距
  • 固定高度：导航栏通常固定高度，保证视觉稳定

常见变体

  • 左中右结构：logo左、导航中、操作按钮右
  • 粘性导航：position: sticky，滚动时保持在顶部
  • 响应式导航：小屏幕折叠成汉堡菜单

5.2 双栏文档布局

左侧目录导航 + 右侧正文内容，是文档站、教程、后台管理系统最经典的结构。本站就是用的这种布局。

实现方案对比

方案 优点 缺点
Grid实现 代码简洁、结构清晰、推荐 较新浏览器支持
Flex实现 兼容性好、灵活 需要设置宽度比例
浮动实现 兼容所有浏览器 需要清除浮动、难维护

最佳实践

  • 侧边栏固定宽度，主内容区弹性占满剩余空间
  • 侧边栏用 position: sticky 实现滚动跟随
  • 主内容区设置最大宽度，超宽屏不拉伸过度

5.3 圣杯布局

经典的完整页面骨架：顶部页眉、底部页脚、中间三栏（左侧导航、主内容、右侧边栏）。因为早年实现难度大，被称为「圣杯」布局。

演进历史

  • 表格时代：用table实现，简单但语义错误
  • 浮动时代：负margin技巧，复杂脆弱
  • Flex时代：Flex实现，简单很多
  • Grid时代：命名区域，代码像结构图一样直观
Grid命名区域是圣杯布局的终极方案：代码结构和视觉结构一一对应，修改布局只需要改一行字符串。

5.4 响应式卡片流

产品列表、图片画廊、功能入口、搜索结果页最常用的布局形式。卡片自动换行，自适应容器宽度。

两种实现方式

设计要点

  • 卡片统一高度，视觉整齐
  • 间距一致，不要用margin，用gap
  • 最小宽度根据内容确定，保证可读性
  • 卡片内边距要充足，避免内容拥挤

5.5 固定侧边栏

页面滚动时，侧边栏保持在视口中不动，方便用户随时切换导航或查看信息。

sticky vs fixed

特性 position: sticky position: fixed
定位基准 相对于最近滚动祖先 相对于视口
占据空间 ✅ 保留原位置，不脱离文档流 ❌ 脱离文档流，不占空间
页眉页脚 ✅ 不会遮挡，滚出去就跟着走 ❌ 永远固定，可能遮挡
兼容性 现代浏览器支持 全浏览器支持
注意：sticky元素的父容器不能有 overflow: hidden，否则sticky会失效。这是最常见的坑。

5.1 导航栏完整代码

.navbar { display: flex; align-items: center; justify-content: space-between; height: 64px; padding: 0 32px; background: #1e293b; color: white; } .navbar__brand { font-size: 18px; font-weight: 600; } .navbar__menu { display: flex; gap: 24px; list-style: none; }

5.2 双栏布局代码

.layout { display: grid; grid-template-columns: 240px 1fr; gap: 24px; max-width: 1200px; margin: 0 auto; padding: 20px; } .sidebar { position: sticky; top: 20px; align-self: start; } .content { min-height: 600px; }

5.3 圣杯布局代码

.page { display: grid; grid-template-columns: 200px 1fr 200px; grid-template-rows: 60px 1fr 50px; grid-template-areas: "header header header" "left main right" "footer footer footer"; min-height: 100vh; } .header { grid-area: header; } .left-sidebar { grid-area: left; } .main-content { grid-area: main; } .right-sidebar { grid-area: right; } .footer { grid-area: footer; }

5.4 响应式卡片流代码

.card-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)); gap: 20px; padding: 20px; } .card { background: white; border-radius: 8px; padding: 20px; box-shadow: 0 2px 8px rgba(0,0,0,0.08); }

5.5 粘性侧边栏代码

.sidebar { position: sticky; top: 20px; align-self: start; width: 240px; }
