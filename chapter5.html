5.1 发布方式概览

把网页发到公网，让所有人访问

5.1 发布方式概览

在前面的章节里，我们都是在自己电脑上双击 .html 文件用浏览器打开。这种方式只能自己看，别人是访问不到的。

要让全世界的人都能通过浏览器访问你的网页，就必须把网页文件发布（部署）到一台一直开机、连着互联网的服务器上。

本教程使用 GitHub Pages：它是代码托管平台 GitHub 提供的免费静态网页托管服务，非常适合新手发布 HTML / CSS / JavaScript 编写的静态网站。它的优点是：不需要自己买服务器、完全免费、还会给你一个固定的网址。

发布成功后，你的网站网址格式是：https://用户名.github.io/仓库名/

5.2 注册GitHub账号

第一步，先去 GitHub 注册一个账号：

① 打开浏览器，访问 github.com，点击 Sign up。

② 依次填写：邮箱地址、设置一个密码、再取一个用户名。

③ 这个用户名会直接出现在你将来的网址里，所以建议用英文、简短好记，比如 alex2026。

④ 注册过程中 GitHub 会发一封验证邮件到你的邮箱，记得打开邮件点击验证链接，否则账号功能不完整。

5.3 创建仓库并上传文件

仓库（Repository）可以理解成 GitHub 上的一个「项目文件夹」，用来存放你的网页文件。

① 登录后，点击右上角 + → New repository，新建仓库。

② 给仓库起个名字，建议用英文（比如 my-web）；下面的公开性一定要选 Public（公开），否则 GitHub Pages 无法免费发布。

③ 创建完成后，进入仓库页面，点击 Add file → Upload files，把本地写好的 index.html、chapter1.html ~ chapter5.html 以及 css、images 等文件夹一起拖进去，拉到最下面点 Commit changes 上传。

特别注意：首页文件必须叫 index.html（全小写）。如果首页叫别的名字，访问网址时浏览器找不到默认页面，就会打不开。

5.4 开启GitHub Pages

文件上传后，网页还不会自动上线，需要手动开启 Pages 服务：

① 进入仓库页面，点击顶部的 Settings（设置）。

② 在左侧菜单找到 Pages 这一项，点进去。

③ 找到 Source，选择 Deploy from a branch。

④ 下面的 Branch 分支选择 main，旁边的目录选择 /(root)（根目录），然后点 Save。

⑤ 保存后耐心等 1~2 分钟，GitHub 正在帮你部署。部署完成后，回到 Pages 页面会出现一个绿色提示，告诉你网站已经上线。

⑥ 在浏览器里访问 https://用户名.github.io/仓库名/，就能看到你自己发布的网站了！

5.5 常见问题排查

问题一：打开网址显示 404。
常见原因：首页文件名不是 index.html；或者 Pages 根本没开启；或者刚上传完、GitHub 还没部署好（多等一会儿）。

问题二：改了本地文件，网站却不更新。
这通常是浏览器缓存造成的。先确认你已经把新文件重新上传到仓库，然后按 Ctrl + F5 强制刷新页面。

问题三：中文显示成乱码（一堆问号或方块）。
这是编码问题。确保文件以 UTF-8 编码保存，并且 <head> 里有 <meta charset="UTF-8"> 这一行。

问题四：点链接打不开或跳错页面。
检查 href 里写的相对路径和实际文件名是否完全一致，特别注意大小写（GitHub 服务器对大小写敏感，Index.html 和 index.html 是两个不同文件）。

记住：每次改完本地文件，都必须重新上传到 GitHub 仓库，网站才会更新，光改本地是不会生效的。

关键代码 ① 发布前检查清单

发布前，对照下面这张清单逐项打勾，能避开 90% 的常见问题。

# ===== 发布前检查清单（逐项打勾）===== # 1. 首页文件名必须是 index.html（全小写），否则打开网址找不到首页 index.html # 2. 仓库必须设为 Public（公开），私有仓库不能免费开启 Pages Repository = Public # 3. Pages 的分支（Branch）选择 main Branch = main # 4. Pages 的目录选择 /(root) 根目录（文件直接放在仓库根目录） Directory = / (root) # 5. 所有页面放在同一目录，互相之间用相对路径链接（如 href="chapter1.html"） 相对路径 = 正确 # 6. 文件编码必须是 UTF-8，并且 head 里写有这一行： <meta charset="UTF-8"> # 7. 保存设置后等 1~2 分钟，再按 Ctrl + F5 强制刷新查看 等待部署 = 1~2 分钟
记忆要点：
1. index.html 是浏览器默认首页，名字一个字母都不能错
2. 仓库必须 Public，分支 main，目录 /(root)，三者缺一不可
3. 每次改完文件都要重新上传，再 Ctrl + F5 刷新

关键代码 ② 网址格式示例

发布成功后，你的网站网址由「用户名」和「仓库名」两部分拼成。

# 网址通用格式： https://用户名.github.io/仓库名/ # 例如：用户名是 alex，仓库名叫 my-web，则完整网址是： https://alex.github.io/my-web/ # 访问首页直接打开这个网址即可； # 访问子页面：https://alex.github.io/my-web/chapter1.html
记忆要点：
1. 用户名就是你注册时取的名字，仓库名就是 New repository 时填的名字
2. 用户名和仓库名要和 GitHub 上写的完全一致（包括大小写）
3. 这个网址是固定不变的，可以直接发给别人访问
